
موقع الخَرَائِطُ الذِّهْنِيَّةُ — دليل التركيب السريع
===================================================

المنتجات المضافة:
- جزء عمّ: 5 دنانير
- جزء تبارك: 3 دنانير
- جزء المجادلة: 3 دنانير
- سورة يس: 3 دنانير
- سورة الكهف: 3 دنانير
- سورة البقرة: 5 دنانير
- الأربعون النووية: 3 دنانير

التوصيل:
- عمّان: 2 د.أ
- باقي المحافظات: 3 د.أ

أولًا: تجهيز ملف الطلبات
------------------------
1. أنشئ ملف Google Sheets جديدًا، وسمّه مثلًا: طلبات الخرائط الذهنية.
2. من داخل الملف: الإضافات / Extensions > Apps Script.
3. احذف الكود الموجود والصق محتوى ملف Code.gs الموجود مع الموقع.
4. احفظ المشروع.
5. شغّل الدالة setupOrdersSheet مرة واحدة ووافق على الصلاحيات.
6. من Deploy > New deployment اختر Web app.
7. Execute as: Me
8. Who has access: Anyone
9. اضغط Deploy وانسخ رابط Web App الذي ينتهي بـ /exec.

ثانيًا: ربط الموقع
------------------
1. افتح ملف app.js.
2. في أول الملف ستجد:
   const SCRIPT_URL = "PUT_YOUR_WEB_APP_URL_HERE";
3. استبدل النص بين علامتي الاقتباس برابط Web App الذي نسخته.
4. احفظ الملف.

ثالثًا: رفع الموقع إلى GitHub Pages
----------------------------------
1. أنشئ مستودع GitHub جديدًا.
2. ارفع الملفات:
   index.html
   styles.css
   app.js
   مجلد assets
3. من Settings > Pages:
   Source: Deploy from a branch
   Branch: main
   Folder: /root
4. احفظ وانتظر ظهور رابط الموقع.

ملف الطلبات
-----------
كل طلب يسجّل تلقائيًا في ورقة اسمها "الطلبات" ويشمل:
التاريخ، رقم الطلب، الاسم، الهاتف، المحافظة، المنطقة، العنوان،
تفاصيل المنتجات والكميات، قيمة الكتب، التوصيل، الإجمالي، الملاحظات، والحالة.

تصدير Excel
-----------
بعد فتح ملف Google Sheets سيظهر في القائمة:
الخرائط الذهنية > تصدير نسخة Excel إلى Drive
وسيتم إنشاء ملف XLSX في Google Drive.

ملاحظات
-------
- رقم الطلب يظهر للعميل بعد التأكد من وجوده في ملف الطلبات.
- يمنع تسجيل نفس رقم الطلب مرتين.
- زر الإرسال يتعطل أثناء الحفظ لمنع الضغط المتكرر.
- الموقع متجاوب للهاتف والكمبيوتر.
